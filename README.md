### What I learned

This project helped me improve my understanding of building reusable card components with HTML and CSS.

I practiced structuring content with semantic HTML and using CSS to closely reproduce a provided design.

I also improved my understanding of:

- Flexbox alignment
- Spacing and sizing
- Border radius
- Box shadows
- Typography
- Hover states
- Responsive layouts
- Using custom fonts with `@font-face`

For example, I used Flexbox to control the layout and alignment of elements inside the card:

```css
.card {
  display: flex;
  flex-direction: column;
}
```

I also practiced adding interactive states to elements:

```css
.card-title:hover {
  cursor: pointer;
}
```
